# علامة · تقييم الطلاب

صفحة تفاعلية يملؤها المشرف لتقييم الطالب/ة، وتطلع بطاقة جاهزة للإرسال لولي الأمر
كصورة أو PDF أو نص على واتساب.

- `public/index.html` — الصفحة كاملة (الشعار مضمّن داخلها)
- `server.js` — خادم Node بسيط بلا اعتماديات (`npm start`، المنفذ من `PORT`)

الحفظ داخل متصفح المشرف فقط (localStorage).
